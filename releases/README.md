# Cinder Vow 2.1.0

[Download the signed release APK](CinderVow-2.1.0.apk?raw=true)

- Android 8.0 and newer; universal APK, portrait orientation.
- English UI, offline dungeon, eight-direction D-pad and independent action buttons.
- Pixel launcher and controls drawn through MCP Aseprite.
- Release signature verified with Android's `apksigner`.
- SHA-256 checksum in `SHA256SUMS`.

The Android 15 emulator instrumentation test passed: offline startup, English UI, portrait viewport, control bounds, D-pad movement, simultaneous movement and attack, cancellation and pause. See `previews/android-verification.json` and `previews/android-portrait.png` in the repository.
